# Crypto Narrative Engineer

Single-page tool for tracking and engineering crypto market narratives — one of the most under-tooled parts of crypto research. Self-contained HTML, no build step.

## Run / Deploy

Open `index.html` directly in a browser, or deploy as a static site:

- **Netlify drag-and-drop:** https://app.netlify.com/drop
- **Netlify CLI:** `netlify deploy --dir="." --prod`
- **GitHub Pages:** Settings → Pages → Source: `main` branch, root

## Stack

Vanilla HTML / CSS / JavaScript. Single 46 KB file. Works offline once loaded.

## Customizing

All markup, styles, and data live in `index.html`. Edit in place — no build pipeline required.
